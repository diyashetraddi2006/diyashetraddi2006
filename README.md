## 🚀 Projects

### 🌧️ Project RainGuard
**Automated Motorized Protective Cover System**

An engineering design project developed during my first semester, focused on designing a motorized protective cover that can deploy and retract to provide hands-free protection for outdoor spaces.

- Explored problem identification and concept generation.
- Worked through product architecture and design evaluation.
- Documented virtual and physical implementation.

📁 [Explore Project RainGuard](https://github.com/diyashetraddi2006/Project_RainGuard)

### 🚗 I²C-Based Smart Vehicle Monitoring and Dashboard
An ESP32-based miniature vehicle monitoring prototype integrating sensors and an OLED dashboard.

- Ambient light monitoring using an LDR and ADS1115.
- Motion and tilt monitoring using MPU6050.
- Obstacle distance measurement using VL53L0X.
- Real-time information display using an SSD1306 OLED.
- Automated lighting and indicator control.

### 🌱 Smart Greenhouse Monitoring System
An IoT-based monitoring system designed to observe environmental conditions using ESP32 and sensors.

- Temperature and humidity monitoring.
- Soil moisture monitoring.
- Gas sensing.
- Data monitoring using ThingSpeak.
